## Overview

This paper investigates whether cross-domain transfer from speech enhancement to deepfake enhancement is feasible. We train a diffusion-based speech enhancement model (DR-DiffuSE) on the LJSpeech dataset and apply it to vocoder-generated speech from the WaveFake dataset without fine-tuning. Our experiments yield a clear negative result: cross-domain transfer does not work. The domain gap between acoustic noise (the training objective) and synthetic artifacts (the target application) is too large for naive transfer to succeed.

---

## Method

We approach audio deepfake enhancement as a conditional generation problem analogous to speech enhancement. Given a synthetic audio deepfake generated by a neural vocoder, our goal is to produce enhanced audio that sounds more natural and human-like.

**DR-DiffuSE Framework:** We adopt the DR-DiffuSE framework, a state-of-the-art diffusion-based method that addresses the condition collapse problem in conditional generation. The framework operates on Mel spectrograms and consists of three components trained sequentially and applied jointly during inference:

1. **Condition Generator** — Produces a preliminary cleaned spectrogram from the input
2. **Conditional DDPM** — Performs iterative denoising conditioned on the generator output
3. **Refinement Network** — Polishes the DDPM output to compensate for stochastic artifacts

**Architectural Variants:** The framework supports two conditioning mechanisms:
- **DiffuSE (Two-Branch)** — Processes input and condition through separate parallel branches with layer-wise feature fusion
- **DiffuSEC (Concatenation)** — Concatenates input and condition along the channel dimension

**Chunked Processing:** Since the model is trained on 3-second segments, we developed a chunked inference approach for full-length audio. The input is divided into overlapping 3-second chunks, processed independently, and reassembled using weighted overlap-add with a Hann window.

## Dataset 
Mounted as read-only volume at /data/lj_volume/voicebank/
 
```
/data/lj_volume/voicebank/
├── clean_trainset_wav/    # 10,480 LJSpeech files
├── noisy_trainset_wav/    # 10,480 WaveFake files
├── clean_testset_wav/     # 2,620 LJSpeech files (held-out)
└── noisy_testset_wav/     # 2,620 WaveFake files (held-out)
```
**Vocoders used:** MelGAN, HiFi-GAN, Parallel WaveGAN, Multi-band MelGAN, WaveGlow

Data is organized in VoiceBank dataset structure as expected by the original DR-DiffuSE repo. No actual VoiceBank data is used — only LJSpeech and WaveFake.

## Training
 
# Step 1: Condition generator
python train.py

# Step 2: DDPM variants
python train_ddpm.py --model DiffuSEC --wandb
python train_ddpm.py --model DiffuSEC --c_gen --wandb
python train_ddpm.py --model DiffuSE --c_gen --wandb

# Step 3: Refiner
python joint_finetune.py --fast_sampling --from_base --wandb

## Inference (Ablations)
# Baseline
python test_ddpm.py --model DiffuSE
python test_ddpm.py --model DiffuSEC

# Best traditional metrics result
python test_ddpm.py --model DiffuSE --c_gen
python test_ddpm.py --model DiffuSEC --fast_sampling

# Best perceptual quality
python test_ddpm.py --model DiffuSE --c_gen --fast_sampling --c_guidance --refine
python test_ddpm.py --model DiffuSEC --c_gen -- c_guidance
